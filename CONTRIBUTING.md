# Contributing

NotYUpscalerZAI is a local Windows image and video enhancement application built with Python, OpenCV, CustomTkinter and bundled FFmpeg.

## Development

Read the README and inspect the existing processing pipeline before changing filters, UI behavior or export handling. Validate changes with representative image and video inputs.

Build/packaging entrypoint: `python build.py`

Keep pull requests focused. Do not commit credentials, private media, generated binaries or unrelated changes.
